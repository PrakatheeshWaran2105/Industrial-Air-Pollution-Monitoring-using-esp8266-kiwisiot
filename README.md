# Industrial-Air-Pollution-Monitoring-using-esp8266-kiwisiot
Industrial Air Pollution Monitoring using NodeMCU ESP8266 and MQ-135 gas sensor to monitor changes in surrounding air quality and transmit real-time sensor readings to the KiwisIoT platform.
Industrial Air Pollution Monitoring Using ESP8266 and KiwisIoT

About the Project

The Industrial Air Pollution Monitoring System is an IoT project designed to monitor air quality conditions in industrial environments and observe changes in surrounding gas concentrations.

Using a NodeMCU ESP8266 microcontroller and an MQ-135 gas sensor, the system detects changes in the surrounding air and collects sensor readings. The collected data is transmitted to the KiwisIoT platform through Wi-Fi, allowing users to remotely monitor air quality readings through an online dashboard.

By integrating KiwisIoT, this project demonstrates a simple approach to industrial air quality monitoring, real-time sensor data visualization, and IoT-based environmental monitoring.
